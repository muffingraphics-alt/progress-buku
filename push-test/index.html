2. Aktifkan uji Firebase Cloud Messaging

Buat proyek Firebase gratis, tambahkan aplikasi Web, lalu isi konfigurasi web yang bersifat publik di bawah. Ambil juga Web Push certificate public VAPID key dari menu Cloud Messaging.

Cara mengambil konfigurasi Firebase
  1. Buka Firebase Console dan buat project MuffinFlow Push Test.
  2. Project settings → General → Your apps → tambah aplikasi Web (</>). Salin nilai firebaseConfig.
  3. Project settings → Cloud Messaging → Web Push certificates → Generate key pair → salin public key.
  4. Jangan salin atau membagikan service account JSON / private key.
Belum terhubung ke Firebase.
Konfigurasi publik disimpan hanya di browser perangkat ini. Token berlaku khusus untuk perangkat/browser dan dapat berubah. Jangan unggah token ke repository publik.
Jika tes Firebase dilakukan ketika halaman ini terlihat, pesan masuk akan muncul di status di atas dan dicoba ditampilkan sebagai notifikasi sistem. Saat halaman ditutup atau tersembunyi, layanan push membutuhkan service worker dan izin browser.

3. Uji push sungguhan saat aplikasi tidak terlihat

  1. Setelah token muncul, buka Firebase Console → Messaging / Campaigns.
  2. Buat notifikasi uji, pilih Send test message, lalu tempel token perangkat FCM.
  3. Pindahkan Chrome ke latar belakang, atau kunci layar Android. Kirim tes dari Firebase Console menggunakan perangkat lain.
  4. Periksa apakah notifikasi sistem muncul dan dapat diketuk. Hasil ini menguji push jarak jauh, bukan bunyi tab Chrome.
Jika pesan tidak muncul, pastikan notifikasi Chrome di Android dan situs GitHub Pages tidak diblokir, mode Jangan Ganggu tidak aktif, dan tidak ada penghemat baterai yang menunda pengiriman.
