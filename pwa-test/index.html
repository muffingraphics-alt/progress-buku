MuffinFlow, sekarang bisa dicoba sebagai aplikasi di HP 🧁

Ini PWA percobaan untuk mencoba ikon di Home Screen, tampilan tanpa bilah alamat, dan pemberitahuan melayang. Data di bawah hanya contoh; login dan data produksi asli tetap berada di Google Apps Script.

Buka MuffinFlow asli ↗
Jika belum ada pilihan Install, buka menu ⋮ Chrome → Tambahkan ke Layar Utama atau Install aplikasi.

📚 Monitoring contoh

Jadwal buku, progres cetak, dan status gudang.
