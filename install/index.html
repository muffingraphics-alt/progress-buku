Pasang MuffinFlow 🧁

Tambahkan ikon muffin ke layar utama Android. Ketuk ikon muffin di layar utama. MuffinFlow asli akan dibuka otomatis, tanpa perlu mengetik alamat lagi.

Buka MuffinFlow asli ↗
Sedang membuka MuffinFlow asli...
Buka halaman ini melalui Chrome Android, lalu ketuk Install MuffinFlow. Jika Chrome belum menampilkan pilihan Install, gunakan menu ⋮ → Tambahkan ke Layar Utama.
Setelah terpasang
  1. Ketuk ikon muffin di layar utama HP.
  2. MuffinFlow asli terbuka otomatis. Jika tidak, ketuk Buka MuffinFlow asli.
  3. Login menggunakan akun yang sama seperti sebelumnya.
Aplikasi utama masih berjalan di Google Apps Script, jadi saat dibuka bisa berpindah ke Chrome. Ini launcher ringan, bukan APK atau PWA penuh. Data buku, kode akses, dan notifikasi tidak diubah.
